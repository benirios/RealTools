  - Sliding expiration, 12h expiry
- Serves additional static files from Assets via PhysicalFileProvider
- Maps default MVC route: {controller=Home}/{action=Index}/{id?}

## Services (summary)
- ProductCatalogService
  - Loads/saves products from Catalog_Assets/products.json
  - GetAll/GetById/Create/Update/Delete, seeding when absent
  - Atomic file writes and slug normalization
- CartStore
  - Singleton in-memory cart storage
  - Uses product service to validate items
  - Note: current cart is global to the server instance (not per-user)
- UserStore
  - Stores users in context/users.json
  - Password hashing: per-user salt + SHA-256
  - Seeds admin and sample customer accounts

## Controllers and features
- HomeController: Index, Privacy, Error
- ProdutosController: catalog listing, filters, product details
- CarrinhoController: view, add, update quantity, remove (POSTs with antiforgery)
- AccountController: login/register/logout (issues claims Name and Role)
- AdminController: protected by [Authorize(Roles = "Admin")] for product management

## Frontend / UX notes
- Shared layout with cart badge and navbar that adapts to roles
- Add-to-cart and cart updates post via POST endpoints and anti-forgery tokens
- Images served from Assets and referenced in Catalog_Assets

## Security & Limitations
- Cookie authentication + roles, antiforgery tokens on POSTs
- Password hashing with salt+SHA256 is functional but consider PBKDF2/BCrypt/Argon2 for production
- Cart is server-wide in-memory: not suitable for multi-user persistence or scaling
- JSON-based persistence is simple but not concurrent-safe; recommended migration to a relational DB
